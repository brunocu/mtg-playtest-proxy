# MTG Playtest Proxy

A browser-based tool for generating printable Magic: The Gathering proxy cards for playtesting. Paste a decklist, get a print-ready PDF or image sheet. Cards are inspired by Unknown Events playtest cards to be ink-friendly for printing on regular office paper. For play, slide a printed proxy into a regular sleeve with a bulk common card behind it for the same weight and feel as a real card.

Ported from [bwproxy](https://github.com/a11ce/bwproxy), a Python CLI with the same purpose.

> **Unofficial Fan Content.** This project is unofficial Fan Content created under the Wizards of the Coast Fan Content Policy. See [ATTRIBUTIONS.md](./ATTRIBUTIONS.md) for full third-party asset credits.

## Features

- Black & white or colored card borders
- US Letter or A4 page format for printing
- Small/scaled card size option to fit more cards per sheet
