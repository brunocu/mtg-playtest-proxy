# Contributing

Thanks for your interest in MTG Playtest Proxy! This is a small hobby project, not actively seeking large scope expansions, but bug fixes and improvements are welcome.

## Dev setup

```sh
npm install
npm run dev
```

This starts the Vite dev server with hot reload.

## Tests

```sh
npm test
```

Runs the test suite via Vitest.

## Before submitting a PR

- Run `npm run build` and `npm test` locally and make sure both pass.
- Explain the "why" in your PR description, not just the "what".

For anything beyond a small fix (a new feature, a significant refactor), please open an issue first to discuss the approach before investing time in a PR.
